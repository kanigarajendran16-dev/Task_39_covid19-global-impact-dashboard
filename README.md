# COVID-19 Global Impact Dashboard

## Veda Technology Data Analytics Internship – Day 39

### Project Overview
The COVID-19 Global Impact Dashboard analyses reported COVID-19 cases, deaths, and vaccination data across countries and over time. The project uses data cleaning, statistical calculations, and visualizations to identify trends and communicate insights clearly.

### Objectives
- Clean and prepare COVID-19 time-series data.
- Analyse daily cases and deaths.
- Calculate 7-day moving averages.
- Compare reported cases and deaths across countries.
- Explore available vaccination indicators.
- Build an interactive dashboard and generate an executive summary report.

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Plotly
- Microsoft Excel
- Google Colab
- ReportLab

### Project Workflow
1. Load the COVID-19 dataset.
2. Handle missing values and duplicate records.
3. Convert dates and numeric columns into appropriate formats.
4. Calculate daily trends and 7-day moving averages.
5. Create country-wise comparisons and visualizations.
6. Build an interactive HTML dashboard.
7. Export cleaned data, Excel analysis, graphs, and a PDF report.

### Project Deliverables
- `cleaned_covid19_data.csv` – Cleaned dataset
- `global_daily_trends.csv` – Daily trend data
- `COVID19_Analysis.xlsx` – Excel analysis workbook
- `interactive_dashboard.html` – Interactive visual dashboard
- `Executive_Summary.pdf` – Executive summary report
- PNG files – Data visualizations

### Key Analysis
- Daily reported COVID-19 cases and deaths
- Seven-day moving averages
- Country-wise reported case comparisons
- Country-wise reported death comparisons
- Vaccination coverage, where data is available

### Dataset Source
Our World in Data – COVID-19 Data Explorer

https://ourworldindata.org/coronavirus

### How to Run
1. Open Google Colab.
2. Create a new notebook.
3. Paste the project Python code into a code cell.
4. Run the code with an active internet connection.
5. Download and extract the generated ZIP file.
6. Open the HTML dashboard in a web browser.

### Important Notes
Reported cases and deaths may not represent all actual infections or deaths. Testing, reporting practices, and data completeness vary across countries and dates. Vaccination indicators may be missing for some locations.

If synthetic demo data is used because the dataset cannot be downloaded, it must not be presented as real COVID-19 statistics.

### Conclusion
This project demonstrates a complete data analytics workflow, from data preparation and exploratory analysis to interactive visualization and report generation.
